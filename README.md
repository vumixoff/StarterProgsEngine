🚀 StarterProgsEngine

Программа для автоматизации запуска нескольких файлов через один файл

✨ Возможности:
• Создание старт файлов в форматах EXE, BAT и VBS
• Одновременный запуск нескольких программ
• Выбор собственной иконки (.ico)
• Настройка названия создаваемого файла
• Выбор папки сохранения
• Современный и удобный интерфейс
• Запуск приложений без консоли
• Portable — не требует установки Python

🛠 Поддерживаемые файлы:
.exe • .bat • .vbs

📦 Подходит для:
• Автозапуска программ
• Рабочих наборов приложений
• Автоматизации Windows
